# Clinic Easy स्टाफ ट्रैकिंग डिवाइस (Beta)

> **स्थिति:** सॉफ़्टवेयर (API + डैशबोर्ड) तैयार है। Firmware लिखा गया है पर किसी असली ESP32 पर अभी टेस्ट नहीं हुआ।
> इसलिए ऐप में यह "Beta · हार्डवेयर जल्द" दिखता है। पहले एक क्लिनिक में 1 हफ़्ता पायलट करें।

## यह कैसे काम करता है

```
 स्टाफ का BLE टैग  ──(ब्लूटूथ, 10-20 मीटर)──▶  ESP32 (क्लिनिक में)  ──(WiFi, हर 20 सेकंड)──▶  /api/presence  ──▶  Supabase
 (चाबी-छल्ला/कार्ड)                               सिर्फ़ सुनता है                                    token से पहचान        staff_presence_events
                                                                                                                         ↓
                                                                                         Admin → स्टाफ ट्रैकिंग: कौन आया, कौन अंदर, कितने घंटे, देर
```

- ESP32 सिर्फ़ **सुनता** है (passive scan)। किसी फ़ोन या टैग से जुड़ता नहीं।
- सर्वर सिर्फ़ उन्हीं टैग को सेव करता है जो Admin ने किसी स्टाफ से जोड़े हैं। मरीज़ों या पड़ोसियों के फ़ोन वहीं फेंक दिए जाते हैं।
- एक व्यक्ति का एक मिनट में ज़्यादा से ज़्यादा एक रिकॉर्ड। 15 मिनट से ज़्यादा न दिखे तो "ब्रेक" माना जाता है।
- Pro नहीं है तो डिवाइस "ऑनलाइन" दिखेगा पर कुछ सेव नहीं होगा।

## हार्डवेयर लागत (एक बार, लगभग; ख़रीदने से पहले Robu.in / Robocraze / Amazon पर दाम देखें)

| चीज़ | कितनी | लगभग दाम |
|---|---|---|
| ESP32 DevKit (WROOM-32, USB-C) | 1 (छोटा क्लिनिक) / 2 (बड़ा) | ₹400-550 हर एक |
| 5V USB चार्जर + केबल | हर ESP32 पर 1 | ₹150-250 |
| छोटा प्लास्टिक केस | हर ESP32 पर 1 | ₹80-150 |
| BLE टैग (iBeacon चाबी-छल्ला / कार्ड, nRF52, बैटरी 1-2 साल) | हर स्टाफ पर 1 | ₹500-1,200 |

**उदाहरण:** 1 ESP32 + 4 स्टाफ टैग ≈ **₹2,700-5,700**। 2 ESP32 + 8 टैग ≈ ₹5,300-11,500।
सबसे सस्ता: टैग की जगह स्टाफ के पुराने Android फ़ोन में मुफ़्त "BLE beacon" ऐप (₹0), पर फ़ोन बंद/बैटरी खत्म हो तो हाज़िरी छूट जाती है।

> स्टाफ के अपने आम फ़ोन का MAC पता काम नहीं करता: Android और iPhone हर कुछ मिनट में ब्लूटूथ पता बदल देते हैं (privacy)। इसलिए टैग या beacon ऐप चाहिए।

## सेटअप (30 मिनट)

1. Supabase SQL Editor में `supabase/migrations/20261119000001_pro_automation.sql` चलाएँ।
2. ऐप में Admin → **स्टाफ ट्रैकिंग** → "डिवाइस जोड़ें" → token कॉपी करें (सिर्फ़ एक बार दिखता है)।
3. Arduino IDE 2 → Boards Manager → "esp32 by Espressif" install → Board: "ESP32 Dev Module"।
4. `esp32-presence-node.ino` खोलें, ऊपर की 4 लाइनें भरें: WiFi नाम, पासवर्ड, साइट का URL, token → Upload।
5. Serial Monitor (115200) में `posted N tags -> HTTP 200` दिखे तो डिवाइस ऑनलाइन है।
6. हर टैग का ID (MAC या iBeacon `uuid:major:minor`) टैग के डिब्बे/ऐप पर लिखा होता है, या Serial Monitor के लॉग से मिलेगा। उसे "टैग जोड़ें" में स्टाफ के नाम से जोड़ें।
7. ESP32 को क्लिनिक के बीच में, ज़मीन से 1.5-2 मीटर ऊपर लगाएँ। बाहर की दीवार के पास नहीं।

## सुरक्षा

- Token का सिर्फ़ SHA-256 hash सेव होता है। डिवाइस खो जाए तो उसे "रोकें" करें और नया जोड़ें।
- **Beta कमी:** firmware अभी HTTPS certificate जाँचता नहीं (`setInsecure`)। असली क्लिनिक से पहले साइट का root certificate pin करना है (`tls.setCACert`)।
- पुराना डेटा: `select public.prune_presence_events();` 90 दिन से पुराने रिकॉर्ड मिटाता है।

## कानूनी (DPDP Act 2023)

- हाज़िरी के लिए कर्मचारी का डेटा "employment" वाले legitimate use में आता है, फिर भी **लिखित नोटिस + सहमति** लें: क्या ट्रैक होता है (सिर्फ़ क्लिनिक के अंदर दिखना), क्यों (हाज़िरी/सैलरी), कितने दिन रखा जाएगा (90 दिन)।
- हर स्टाफ अपना रिकॉर्ड देख सकता है (RLS: `presence_events_own_read`)।
- ड्यूटी के बाहर या क्लिनिक के बाहर कोई ट्रैकिंग नहीं। GPS नहीं।

## स्मार्टवॉच (जल्द, ईमानदार स्थिति)

| तरीका | हकीकत |
|---|---|
| सस्ती ब्लूटूथ वॉच (Noise, boAt, Fire-Boltt) | कोई खुला API नहीं, और ब्लूटूथ पता बदलता रहता है। सीधे हमारे सिस्टम से जोड़ना **संभव नहीं**। |
| Wear OS / Galaxy Watch | हमारा अपना छोटा वॉच-ऐप बनाकर BLE beacon की तरह चला सकते हैं (वॉच = टैग)। बैटरी ज़्यादा खर्च होगी। |
| Android फ़ोन + Health Connect | सहमति से स्टेप्स/हार्ट-रेट पढ़ सकते हैं (डॉक्टर की थकान/वेलनेस), Play Store ऐप चाहिए। |
| Apple Watch | iPhone ऐप + HealthKit चाहिए, बाद में। |

सुझाव: पहले **BLE टैग** से हाज़िरी (सस्ता, भरोसेमंद), फिर Play Store वाले Android ऐप में Health Connect।
